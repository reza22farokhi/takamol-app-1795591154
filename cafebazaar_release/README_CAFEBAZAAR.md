# راهنمای آماده‌سازی انتشار در کافه‌بازار (اپلیکیشن آموزشی تکامل)

- **نام برنامه**: اپلیکیشن آموزشی تکامل
- **شناسه بسته (`packageName`)**: `ir.takamol.app1795591154`
- **نسخه**: `1.0.0 (1)`

## وضعیت فعلی
این بسته توسط ایجنت `CafeBazaarApkAgent` در محیط Termux آماده شده است.
فایل workflow مربوط به ساخت خودکار APK در مسیر `.github/workflows/build_apk.yml` قرار داده شده است تا در صورت قرار گرفتن پروژه در GitHub Actions، خروجی APK به‌صورت خودکار ساخته شود.

## چک‌لیست انتشار در کافه‌بازار
1. ساخت فایل APK یا AAB نهایی و امضاشده (`release` + `Keystore`).
2. حفظ کلید امضا برای انتشار نسخه‌های بعدی در کافه‌بازار.
3. تکمیل اطلاعات برنامه، آیکون، اسکرین‌شات‌ها و قوانین محتوایی در پنل توسعه‌دهندگان کافه‌بازار.
